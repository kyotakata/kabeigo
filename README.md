# 壁囲碁 — Wall Go

Netflix「デビルズプラン（Devil's Plan）」シーズン2 に登場した戦略ボードゲーム「壁囲碁」をブラウザで遊べるようにしました。

## 🎮 遊び方

**[▶ プレイする](https://kabeigo.vercel.app/)**

<img src="https://img.shields.io/badge/対戦-2人%20or%203人%20or%20CPU-blue" alt="2人対戦 / 3人対戦 / CPU対戦">

- **2人対戦** — 1台の端末で交互にプレイ
- **3人対戦** — 壁破壊ルール付きの3人プレイ
- **CPU対戦** — 初心者 / 中級者 / 上級者の3段階（2人戦）

## 📖 ルール

### 2人戦

| 項目 | 内容 |
|------|------|
| ボード | 7×7マス |
| 駒数 | 各プレイヤー4個（初期配置2個＋追加配置2個） |
| ターン | 先手→後手の交互 |

### 3人戦

| 項目 | 内容 |
|------|------|
| ボード | 7×7マス |
| 駒数 | 各プレイヤー2個（初期配置なし） |
| 配置順 | 1番→2番→3番→3番→2番→1番 |
| ターン | 1番→2番→3番の順に繰り返し |

### ターンの流れ

1. **駒を移動** — 自分の駒1つを上下左右に1～2マス移動
2. **壁を設置** — 移動先の隣接する辺に壁を1つ置く

### 制約
- 他の駒を飛び越えたり、壁を通り抜けることは不可
- 2マス移動で折り返す（1歩進んで元の方向に戻る）ことは可能

### 終了条件
- 壁によって全プレイヤーの領域が完全に分離されたらゲーム終了
- **より広い領域を持つプレイヤーの勝利**

### 壁破壊（3人戦のみ）
- 各プレイヤーはゲーム中 **1回だけ** 壁破壊を宣言できる
- 宣言後、移動ルート上の壁を1枚壊しながら移動可能
- 確定した領地の壁を壊して相手の領地を狭めることもできる
- 未使用のまま終了してもそのままゲーム終了

## 🛠 技術

- HTML / CSS / JavaScript のみ（フレームワーク不使用）
- 単一HTMLファイルで完結
- Vercel でホスティング
