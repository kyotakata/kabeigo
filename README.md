# 壁囲碁 — Wall Go

Netflix「デビルズプラン（Devil's Plan）」シーズン2 に登場した戦略ボードゲーム「壁囲碁」をブラウザで遊べるようにしました。

## 🎮 遊び方

**[▶ プレイする](https://kabeigo.vercel.app/)**

<img src="https://img.shields.io/badge/対戦-2人%20or%20CPU-blue" alt="2人対戦 or CPU対戦">

- **2人対戦** — 1台の端末で交互にプレイ
- **CPU対戦** — 初心者 / 中級者 / 上級者の3段階

## 📖 ルール

| 項目 | 内容 |
|------|------|
| ボード | 7×7マス |
| 駒数 | 各プレイヤー4個（初期配置2個＋追加配置2個） |
| ターン | 先手→後手の交互 |

### ターンの流れ

1. **駒を移動** — 自分の駒1つを上下左右に1～2マス移動
2. **壁を設置** — 移動先の隣接する辺に壁を1つ置く

### 制約
- 他の駒を飛び越えたり、壁を通り抜けることは不可
- 2マス移動で折り返す（1歩進んで元の方向に戻る）ことは可能

### 終了条件
- 壁によって全プレイヤーの領域が完全に分離されたらゲーム終了
- **より広い領域を持つプレイヤーの勝利**

## 🛠 技術

- HTML / CSS / JavaScript のみ（フレームワーク不使用）
- 単一HTMLファイルで完結
- Vercel でホスティング
